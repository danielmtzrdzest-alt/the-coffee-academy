# Examen — Módulo 08: Limpieza, desinfección y código de colores

## Pregunta 1
¿Cuál es el rango de concentración requerido para el desinfectante de amonio cuaternario usado en la barra?

- [ ] 100 a 200 ppm
- [x] 200 a 400 ppm
- [ ] 500 a 800 ppm
- [ ] Más de 1000 ppm

**Pista:** Piensa en el rango estándar de seguridad para sanitizantes en servicios de alimentos, medido en partes por millón.

## Pregunta 2
¿Cada cuánto debe cambiarse y verificarse la solución desinfectante con tiras reactivas?

- [ ] Cada 4 horas
- [ ] Al final de cada turno
- [x] Cada 2 horas
- [ ] Una vez al día por la mañana

**Pista:** Considera la frecuencia necesaria para mantener la solución fresca y efectiva durante un turno ocupado.

## Pregunta 3
¿Qué área está asociada al color Azul en el sistema de código de colores?

- [ ] Baños y lavabos
- [ ] Pisos internos y bodegas
- [x] Áreas de preparación de alimentos y bebidas
- [ ] Asientos de clientes y mobiliario externo

**Pista:** Este color representa la zona más sensible donde realmente se manipulan bebidas y alimentos.

## Pregunta 4
Si estás limpiando el interior de la vitrina de pan, ¿qué esponja debes usar?

- [ ] La esponja negra/gris
- [ ] La esponja roja
- [x] La esponja verde
- [ ] Una fibra de acero

**Pista:** Un color es para contacto con alimentos y otro para superficies sin contacto.

## Pregunta 5
¿Cuál es el paso crítico de seguridad antes de limpiar equipo eléctrico como la cafetera o la prensa panini?

- [ ] Aplicar agua directamente a los elementos calientes
- [x] Dejar que el equipo se enfríe
- [ ] Mantener la máquina prendida para derretir grasa
- [ ] Usar el trapo rojo de baños para mejor agarre

**Pista:** Considera el estado físico de la máquina y la seguridad de quien limpia.

## Pregunta 6
¿Cuál es un requisito para los botes de basura del frente (FOH)?

- [ ] Deben permanecer destapados para fácil acceso
- [x] Deben estar rotulados con la palabra "Basura"
- [ ] Solo deben vaciarse cuando estén 100 % llenos
- [ ] Deben guardarse dentro de los baños

**Pista:** Este requisito tiene que ver con cómo identifican el bote los clientes y el personal.

## Pregunta 7
¿Cuál es el rango aceptable de cloro residual libre en el agua usada para bebidas?

- [ ] 0.0 a 0.1 ppm
- [x] 0.2 a 1.5 ppm
- [ ] 2.0 a 5.0 ppm
- [ ] 10.0 a 20.0 ppm

**Pista:** El rango inicia ligeramente por encima de cero para garantizar seguridad pero termina antes de que el agua sepa a químico.

## Pregunta 8
Al usar un kit de pastillas DPD para probar el agua, ¿cuál es una instrucción clave para asegurar una lectura precisa?

- [ ] Tocar la pastilla con los dedos para romperla
- [ ] Esperar 10 minutos antes de leer el resultado
- [x] No tocar la pastilla DPD con los dedos
- [ ] Mezclar la pastilla con la solución de amonio cuaternario

**Pista:** Piensa cómo el manejo del reactivo puede interferir con la medición.

## Pregunta 9
Respecto a los baños, ¿cuál de las siguientes es una práctica prohibida?

- [ ] Usar un bote de basura con pedal
- [x] Guardar químicos o utensilios de limpieza dentro del baño
- [ ] Verificar que el espejo esté limpio y sin manchas
- [ ] Reponer jabón y toallas de papel

**Pista:** Considera las reglas sobre dónde deben guardarse los químicos peligrosos y las herramientas de mantenimiento.

## Pregunta 10
¿Qué se debe hacer si se encuentra la concentración de desinfectante fuera del rango 200–400 ppm en una revisión?

- [ ] Agregar más concentrado al balde existente
- [ ] Seguir usándola hasta el próximo chequeo a las 2 horas
- [x] Descartar la solución, preparar una nueva y volver a verificar
- [ ] Diluirla con agua caliente

**Pista:** El protocolo más seguro implica un reset completo de la solución sanitizante.
